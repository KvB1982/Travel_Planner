# iOS- und iPadOS-App

Hier entsteht die native App in Swift und SwiftUI. Der Einstieg erfolgt, sobald der Mac mit Xcode bereitsteht.

Geplante Bausteine, siehe [Konzept](../docs/Konzept.md) Abschnitt 7.1:

- App mit `NavigationSplitView` für iPhone und iPad
- Share Extension als Einstiegspunkt für Links aus Safari und aus den Apps der Plattformen
- Auslesen auf dem Gerät für Plattformen, die den Server sperren (FeWo-direkt, Casamundo)

Die App spricht ausschließlich mit der API aus `../backend`. Die Schnittstelle ist in [docs/API.md](../docs/API.md) beschrieben.
